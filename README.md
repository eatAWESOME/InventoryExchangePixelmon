# InventoryExchangePixelmon

Add-on to [InventoryExchange](https://github.com/eatAWESOME/InventoryExchange) for [Pixelmon](https://reforged.gg).

Awards EMC and adds transmutation knowledge for certain Pixelmon events.

EMC awarded is 1x CP for defeating a pokémon and 5x CP for catching a pokémon. CP is calculated as `((hp + attack + defense + specialAttack + specialDefense + speed) * level * 6) / 100`.
